# Figure 2 中文详细解读：TCGA-LIHC预后引擎的内部验证

## 一句话结论

在363名TCGA-LIHC患者、129例死亡事件的严格5×5重复嵌套交叉验证中，临床变量与15个代谢基因联合构建的随机生存森林M4具有最好的平均内部性能和较稳定的敏感性结果；但是经预先规定的多重比较校正后，M4相对临床Cox基线M1的优势没有达到统计学显著，因此只能称为“暂定主要候选模型”，不能称为已经证明显著优于临床模型。

## 为什么要做这张图

Agent系统需要调用一个可信的定量工具。Figure 2回答的不是“LLM是否聪明”，而是底层预后工具本身是否经过无数据泄漏的训练和评估。它同时展示：

1. 五种模型的总体判别能力。
2. 模型差异是否超过统计不确定性。
3. M4折外风险能否区分不同生存结局。
4. 预测概率误差是否较小。
5. 改变纳入标准后结果是否稳定。

如果没有这张图，Figure 4中的Agent报告即使格式正确，也可能只是忠实调用了一个未经验证的模型。

## 使用的数据

- 数据来源：TCGA-LIHC官方肝细胞癌队列。
- 最终建模人数：363人。
- 死亡事件：129例，事件率35.5%。
- 表达特征：15个预先锁定的代谢相关基因，使用`log2(TPM+1)`表达。
- 临床特征：年龄、AJCC分期、肿瘤分级。
- 验证设计：5次重复，每次5个外层测试折，共25个外层测试结果。
- 每名患者在每次重复中恰好进入一次外层测试集，因此每个模型共有363×5=1,815条折外预测。
- 五个模型合计9,075条折外预测。

五种比较模型为：

- M1：仅临床变量的Cox比例风险模型。
- M2：仅15基因的Elastic-net Cox模型。
- M3：临床变量加15基因的Elastic-net Cox模型。
- M4：临床变量加15基因的随机生存森林。
- M5：临床变量加15基因的DeepSurv神经网络。

## 分析方法

### 重复嵌套交叉验证

外层交叉验证只负责评估，内层交叉验证只负责选择超参数。缺失值处理、标准化、哑变量编码和超参数搜索均在训练折内部完成，不能提前看到外层测试患者。这种设计用于减少数据泄漏和过度乐观的性能估计。

### Harrell C与Uno C

两者都衡量模型能否把较早发生死亡事件的患者排在更高风险位置。0.5接近随机排序，1.0为完全正确。Uno C通过逆概率删失加权处理随访截止造成的信息不完整，权重只能由相应外层训练数据估计。

### 时间依赖AUC

分别在12、36和60个月评价模型能否区分指定时间前发生事件和仍生存的患者。它是随时间变化的判别指标，不应和普通二分类ROC AUC混为一谈。

### Brier分数与IBS

Brier分数衡量预测的生存概率与实际结局之间的误差，越低越好。IBS把多个时间点的Brier分数整合成一个值，同时反映区分能力和概率准确性。

### 患者层面配对Bootstrap

比较两个模型时，每次有放回抽取同一批患者，两个模型和5个重复使用同一抽样患者；先在每个重复内计算差异，再对5个重复取平均。共形成1,000个有效重抽样结果，得到95%置信区间和P值。四个正式比较在各指标家族内使用Bonferroni校正。

## 各面板如何阅读

### Panel a：25个外层测试折的判别能力

每个小点代表一个外层测试折，箱线图表示25折的分布，粗色线表示算术平均值，虚线0.5表示随机排序。

平均结果为：

- M1：Harrell C 0.597，Uno C 0.615。
- M2：Harrell C 0.619，Uno C 0.601。
- M3：Harrell C 0.623，Uno C 0.608。
- M4：Harrell C 0.641，Uno C 0.627。
- M5：Harrell C 0.479，Uno C 0.486。

M4在两种C-index的平均值中均最高；M5平均接近或低于0.5，并且折间波动较大。Panel a是描述性分布，不能仅凭箱线图间距宣布统计学显著。

### Panel b：预先规定的模型配对比较

点表示“模型A减比较模型”的平均指标差，横线表示95%置信区间，正值偏向模型A。

- M4对M1的Harrell C差异为+0.078，95% CI为+0.017至+0.138；原始P=0.024，但Bonferroni校正后P=0.096，不显著。
- M4对M1的Uno C差异为+0.014，95% CI为−0.041至+0.065，校正后P=1.000，不显著。
- M5对M1的Uno C差异为−0.130，95% CI为−0.186至−0.074，校正后P=0.008，说明M5在Uno C上显著更差。

因此“平均最好”和“显著优于”是两个不同结论。本图只支持前者。

### Panel c：M4折外风险与生存

M4在不同外层折产生的原始风险数值尺度不完全相同，因此先在各测试折内转换成与结局无关的风险百分位，再对每名患者5次折外百分位取平均。按中位数分成低风险182人和高风险181人。

- 高风险组死亡82例，低风险组死亡47例。
- 高风险相对低风险HR=2.21，95% CI 1.54–3.16。
- 双侧log-rank P=9.50×10⁻⁶。

这说明M4折外风险排序与总生存显著相关。但分组阈值仅用于内部可视化，没有在独立外部队列验证，不能当作临床使用的风险界值。

### Panel d：12、36和60个月预测误差

细线连接同一个外层折中的M1和M4，使读者看到每个折的配对变化。大点和误差线表示25折均值及近似95%置信区间。M4平均IBS为0.184，低于M1的0.196，说明M4的整体概率误差较小，但该面板主要是补充性能维度，不等于证明临床获益。

### Panel e：敏感性分析

三种队列定义分别是：

- SA1：主要队列，N=363。
- SA2：排除年龄小于18岁的2名患者，N=361。
- SA3：只保留分期和分级完整者，N=338。

M4在三种分析中的Harrell C分别约0.641、0.639和0.630，均排名第一；IBS分别约0.184、0.185和0.180，也均排名第一。Uno C在SA1和SA2排名第一，在SA3排名第三。说明主要结论对年龄异常值和临床变量缺失处理总体稳健，但不同指标的排名并非完全不变。

## 对整篇论文的意义

Figure 2建立Agent系统底层数值工具的可信基础。它支持将M4选为后续研究的暂定主要模型，也透明展示了统计学不显著、M5失败以及部分指标排名变化。对论文而言，这种“展示优势同时保留负结果”的做法比只报告最好数字更能经受审稿。

同时，这张图明确了LLM的责任边界：Agent只能读取和解释这些冻结的折外结果，不能重新调参、改变风险方向或制造更好看的指标。

## 能说明什么、不能说明什么

可以说明：

- M4在TCGA-LIHC内部验证的多项平均指标中表现最好。
- M4折外风险与总生存显著相关。
- M4在三种队列定义下总体保持较好排名。
- M5在当前样本量和实现下表现差且不稳定。

不能说明：

- 没有证明M4显著优于M1；正式校正后的M4对M1比较不显著。
- 不能把内部中位数风险分组当作临床阈值。
- 不能据此宣称M4已完成独立外部验证。
- 不能宣称模型能够指导治疗或适用于所有HCC患者。

## 术语解释

- **Nested cross-validation（嵌套交叉验证）**：外层评估性能、内层选择模型设置的双层数据划分。
- **Fold（折）**：把数据分成若干份中的一份；轮流作为测试集。
- **OOF prediction（折外预测）**：患者的预测由没有用该患者训练的模型产生。
- **Data leakage（数据泄漏）**：训练过程提前利用测试集信息，使结果虚高。
- **Hyperparameter（超参数）**：训练前或内层验证中选择的设置，例如惩罚强度、树数量。
- **Cox proportional hazards model（Cox比例风险模型）**：估计特征与相对死亡风险关系的经典生存模型。
- **Elastic net（弹性网络）**：结合L1和L2惩罚的回归方法，可缩小或筛除系数。
- **RSF（Random Survival Forest，随机生存森林）**：用多棵生存树处理非线性和变量交互的集成模型。
- **DeepSurv**：以神经网络表示风险函数的Cox型生存模型。
- **Harrell C-index**：衡量患者风险排序与实际生存顺序一致程度的指标。
- **Uno C-index**：使用IPCW减轻删失偏倚的C-index。
- **IPCW**：逆概率删失加权；对仍可提供信息的患者给予统计权重。
- **Time-dependent AUC（时间依赖AUC）**：指定时间点的生存判别能力。
- **Brier score**：预测概率与实际结局之间的平方误差。
- **IBS（Integrated Brier Score）**：一段时间内Brier分数的积分平均。
- **Bootstrap**：从患者中有放回地重复抽样，用于估计不确定性。
- **95% CI（95%置信区间）**：在重复抽样意义下描述估计不确定性的区间。
- **Bonferroni correction**：进行多个比较时把显著性标准变严格，降低偶然阳性。
- **Kaplan–Meier curve**：随时间估计生存概率的阶梯曲线。
- **Hazard ratio（HR，风险比）**：两组瞬时事件风险的相对比值。
- **Log-rank test**：比较两条生存曲线是否存在总体差异的检验。
- **Sensitivity analysis（敏感性分析）**：改变合理的数据处理规则，检查主要结论是否保持。
