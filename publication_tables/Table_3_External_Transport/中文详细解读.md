# Table 3 中文详细解读：冻结代谢基因组件的外部跨平台迁移结果

## 一句话结论

Table 3给出两个独立芯片队列的精确外部结果：冻结基因评分在GSE14520 GPL3921中具有Harrell C 0.629和Uno C 0.635，并呈现显著的连续风险和冻结阈值分层关联；GSE116174 GPL570方向一致，但样本较小、置信区间更宽，连续风险P=0.057。结果支持探索性基因组件迁移，不支持完整M4外部验证。

## 为什么要做这张表

Figure 3强调视觉证据，Table 3负责保存每个外部队列的：

- 样本数和死亡事件数。
- Harrell C与Uno C及其95% CI。
- Uno C实际使用的截断时间。
- 连续风险评分每增加1 SD的HR。
- 比例风险假设检验。
- 冻结阈值下高低风险人数、HR和log-rank P值。

精确表格可以防止只看图形位置而忽略小样本不确定性，也让审稿人核查外部分析是否进行了结局驱动调参。

## 使用的数据

### GSE14520 GPL3921

- 221名患者。
- 85例死亡，占38.5%。
- 15/15个冻结代谢基因可映射。

### GSE116174 GPL570

- 64名患者。
- 27例死亡，占42.2%。
- 15/15个冻结代谢基因可映射。

### 排除队列

GSE14520 GPL571为21例完整OS患者、11例死亡。其样本量不足以支持稳定主分析，因此分析前排除，不产生性能记录。

### 模型输入

外部分析使用TCGA来源的冻结M2T基因评分。基因列表、探针映射规则、标准化方式、惩罚系数和TCGA中位数阈值均在查看外部结局前锁定。外部队列不提供完整M4所需的同质RNA测序和临床输入。

## 分析方法

### 判别能力

Harrell C和Uno C分别计算。两者越高，风险排序越好；0.5接近随机。每个队列使用1,000次患者层面Bootstrap获得95%百分位置信区间。

Uno C需要选择截断时间tau，以避免在随访尾部因极少患者仍被观察而产生不稳定权重。表中实际tau为GSE14520的48.0个月和GSE116174的44.8个月。

### 连续风险关联

每个队列内先计算风险评分标准差，再以“每增加1 SD”为单位拟合单变量Cox模型。这样可在不同数值尺度的芯片平台之间比较效应大小。标准差计算不使用生存结局。

### 比例风险检验

PH检验使用ranked-time转换，检查风险评分的相对效应是否随时间明显变化。P值较大表示没有发现违反PH假设的证据，但不能证明假设绝对正确。

### 冻结阈值分组

TCGA开发队列M2T评分中位数−0.0100作为固定cutoff，不改变地应用到两个外部队列。高低风险HR使用单变量Cox模型，曲线差异使用log-rank检验。没有在外部数据中搜索最优分界点。

## 连续性能部分如何解读

### GSE14520 GPL3921

- Harrell C=0.629，95% CI 0.571–0.687。
- Uno C=0.635，95% CI 0.574–0.696。
- 风险评分每增加1 SD，HR=1.58，95% CI 1.26–1.99。
- Wald P<0.001。
- PH检验P=0.815。

该队列的C-index区间均在0.5以上，连续风险HR区间也在1以上，形成方向一致的外部探索性证据。PH检验未提示明显比例风险违背。

### GSE116174 GPL570

- Harrell C=0.603，95% CI 0.492–0.711。
- Uno C=0.601，95% CI 0.483–0.712。
- 每1 SD风险HR=1.47，95% CI 0.99–2.20。
- Wald P=0.057。
- PH检验P=0.838。

点估计方向与大队列相同，但C-index置信区间跨0.5，HR区间跨1，P值略高于0.05。它提供一致性线索而不是确定性阳性结论。宽区间主要反映64例患者、27例事件带来的统计不精确。

## 冻结阈值分层部分如何解读

### GSE14520 GPL3921

- 高风险113人，低风险108人。
- 高风险对低风险HR=2.13，95% CI 1.37–3.31。
- log-rank P<0.001。

### GSE116174 GPL570

- 高风险35人，低风险29人。
- HR=2.47，95% CI 1.08–5.66。
- log-rank P=0.027。

两个队列的高风险组均显示更差生存。小队列HR点估计更高，但置信区间明显更宽，不能据此声称小队列效果更强。HR大小同时受样本构成和随机波动影响。

## 对整篇论文的意义

Table 3补足内部验证无法回答的可迁移性问题。其优势在于模型和阈值均冻结、两个队列独立分析、没有合并制造更大的样本量，也没有用外部结局重新调优。

该表为论文提供“基因组件跨平台方向一致”的证据，同时清楚展示小队列不确定性。它应作为Figure 3的精确数值来源，并与Table 1的人群差异联合解读。

## 能说明什么、不能说明什么

可以说明：

- 冻结基因组件在两个独立芯片队列中产生方向一致的预后关联。
- 大队列的判别和连续风险证据较稳定。
- 冻结TCGA阈值在两个队列中均形成显著生存分层。
- 外部分析没有结局驱动的映射、选基因、调系数、调阈值或再校准。

不能说明：

- 不是RNA测序加临床变量的完整M4外部验证。
- 不能把小队列P=0.057描述为统计学显著。
- 不能比较两个队列HR点估计后断言一个队列效果更强。
- 不能将风险分层解释为治疗决策或个体获益。
- GPL571未分析，不能填入任何性能数值。

## 术语解释

- **Transport score（迁移评分）**：把开发队列冻结的评分规则应用到不同平台后的风险分数。
- **Independent cohort（独立队列）**：未用于模型训练、来源独立的患者集合。
- **Harrell C**：基于可比较患者对的风险排序一致性。
- **Uno C**：用IPCW减轻删失造成偏倚的排序指标。
- **Tau（τ，截断时间）**：Uno C只评价到该时间点，避免随访尾部权重极端。
- **HR per 1 SD**：风险评分每增加一个标准差对应的相对瞬时死亡风险。
- **Wald test**：根据估计系数与其标准误计算P值的检验。
- **PH assumption**：Cox模型假定相对风险随时间大致稳定。
- **Ranked-time transformation**：PH诊断中对时间进行排序变换的方法。
- **Frozen cutoff（冻结界值）**：在外部结局不可见时预先确定并保持不变的分组阈值。
- **Log-rank P value**：比较两条完整生存曲线差异的P值。
- **Precision（精度）**：估计的不确定性大小，通常由置信区间宽度反映。
- **Point estimate（点估计）**：例如C=0.603或HR=1.47的单一最佳估计。
- **No pooling（不合并）**：分别分析每个队列，保留平台和人群差异。
- **Outcome-driven tuning（结局驱动调优）**：利用外部生存结果选择最有利设置，会造成乐观偏倚；本研究禁止。
