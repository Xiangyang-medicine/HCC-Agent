# Table 3 title

**Table 3. External cross-platform transport of the frozen metabolic-gene prognostic component**

# Notes

The frozen TCGA-derived gene-only transport score was evaluated separately in two independent hepatocellular carcinoma microarray cohorts. External outcomes were not used for probe mapping, expression standardisation, coefficient estimation, hyperparameter tuning, cutoff selection, or recalibration.

Harrell C and Uno C are reported with patient-level bootstrap 95% percentile confidence intervals from 1,000 valid resamples. Uno C used the cohort-specific truncation time shown in the table. The continuous-score hazard ratio (HR) is reported per 1-standard-deviation higher transported score using a univariable Cox model; the score standard deviation was calculated within each cohort without using survival outcomes. The proportional-hazards (PH) test used the ranked-time transformation.

For the categorical analysis, higher- and lower-risk groups were defined using the median transported score in the locked TCGA derivation cohort (−0.0100). This cutoff was applied unchanged to both external cohorts. The HR compares higher with lower risk. No external outcome-driven cutoff was selected.

GSE14520 GPL571 (N=21, 11 events) was not analysed because the sample size was insufficient for a stable main analysis. The reported results evaluate transport of the frozen gene-only component; they do not constitute external validation of the RNA-seq-plus-clinical M4 model, clinical utility, or deployment readiness.

Abbreviations: CI, confidence interval; HCC, hepatocellular carcinoma; HR, hazard ratio; OS, overall survival; PH, proportional hazards; SD, standard deviation.
