# Table 1 中文详细解读：开发队列与外部迁移队列的基本特征

## 一句话结论

Table 1说明三个人群在样本量、死亡事件率、年龄、性别、分期和检测平台上存在明显差异，但均具备完整的15个锁定代谢基因输入。TCGA-LIHC用于模型开发和内部验证，两个芯片队列只用于冻结基因组件的探索性跨平台迁移；GPL571因完整生存病例只有21例而未进入分析。

## 为什么要做这张表

任何模型性能都依赖研究人群。审稿人首先会问：训练集和外部队列是否相似、事件数是否足够、临床变量是否完整、检测技术是否一致。Table 1提供这些基础信息，防止读者把后续性能差异简单归因于算法，而忽略队列组成和平台差异。

它还承担患者流和数据边界的核对作用：

- 哪个队列用于开发。
- 哪些队列只用于外部基因组件迁移。
- 哪些变量在外部数据中不可用。
- 哪个小队列被排除以及排除发生在何时。

GSE14520 GPL571有21例完整OS病例和11例事件。研究在性能分析前基于样本量不足将其排除。因此它只出现在来源和排除记录中，不出现在任何性能比较中。

## 分析方法

Table 1主要是描述性统计，不进行队列间显著性检验。

- 连续变量使用中位数和四分位距，因为年龄和观察时间不一定符合正态分布。
- 分类变量使用人数和百分比。
- 百分比分母为对应队列的分析病例数。
- “观察到的OS或删失时间”是实际记录的死亡时间或最后随访时间，不是通过反向Kaplan–Meier估计的中位随访。
- 外部队列缺失的肿瘤分级标为NA，没有根据其他变量推测或插补。
- 分期类别为便于跨队列展示统一为I、II和III–IV，但保留缺失情况。

不做队列间P值比较是合理的，因为三个队列并非随机分配的实验组，且研究目的不是证明基线特征相同，而是透明展示差异。

## 如何阅读每一行

### Analysis role

指出数据在研究中的职责。TCGA是开发和重复嵌套交叉验证队列；两个GEO队列是次要探索性跨平台迁移队列。这一行决定后续结果能够使用什么措辞。

### Expression technology

TCGA使用RNA测序，外部队列使用芯片。平台不同是Figure 3需要探针映射和结局盲标准化的原因。

### Patients与Deaths

患者数决定估计精度，死亡事件数决定生存分析实际包含的信息量。GSE116174只有27例死亡，因此其C-index和HR置信区间比GSE14520更宽。

### Observed OS/censoring time

这是每名患者从基准时间到死亡或最后随访的记录时长。它同时混合了死亡时间和删失时间，不能直接理解成“患者的中位生存期”。

### Age与Male sex

外部队列比TCGA更年轻、男性比例更高，提示人群组成不同。这种差异可能影响模型迁移表现，也说明不能把三个队列简单合并。

### Stage与Grade

GSE116174中II期占比70.3%，与TCGA和GSE14520明显不同；外部队列没有可用的统一分级。这正是完整临床加基因M4无法直接外部验证的关键原因之一。

### Locked metabolic genes available

三个纳入队列均有15/15基因，说明基因组件具备最低技术输入条件。它不表示测量尺度相同，也不表示完整M4输入完整。

## 对整篇论文的意义

Table 1为Figure 2和Figure 3提供分母和人群背景。它解释了为什么：

1. TCGA结果称为内部验证。
2. 外部分析只能针对基因组件。
3. 两个外部队列需要分别报告。
4. 小队列结果的不确定性更大。
5. GPL571只能作为排除记录。

这张表是防止过度外推的重要材料，也是审稿人核查选择偏倚和可推广性的起点。

## 能说明什么、不能说明什么

可以说明：

- 三个分析队列的样本量、事件率和主要临床组成。
- TCGA与外部队列在平台和人群结构上存在明显差异。
- 三个纳入队列都可映射15个锁定基因。
- GPL571因N=21在分析前排除。

不能说明：

- 描述性差异不能证明某个变量导致模型性能变化。
- 没有队列间P值不等于队列相同。
- 15个基因可用不等于表达测量完全可比。
- 不能由观察时间中位数推断真正的中位随访或中位生存。
- 外部队列不能支持完整M4外部验证。

## 术语解释

- **Cohort（队列）**：按统一规则纳入的一组研究对象。
- **Development cohort（开发队列）**：用于建立模型和内部评估的数据。
- **External transport cohort（外部迁移队列）**：独立来源、用于测试冻结组件能否迁移的数据。
- **OS（Overall Survival，总生存）**：从定义的起点到任何原因死亡的时间。
- **Event（事件）**：本研究中指死亡。
- **Censoring（删失）**：随访结束时未观察到死亡，只知道患者至少生存到最后记录时间。
- **Median（中位数）**：排序后位于中间的数值。
- **IQR（四分位距）**：第25百分位到第75百分位的范围。
- **n (%)**：人数及其占该队列总人数的百分比。
- **AJCC/TNM stage**：依据肿瘤范围、淋巴结和远处转移等确定的临床分期体系。
- **Tumour grade（肿瘤分级）**：病理形态与正常组织相似程度的分级。
- **NA（Not available）**：锁定输入中没有该变量，不代表数值为0。
- **RNA-seq**：通过测序估计RNA表达的技术。
- **Microarray**：通过探针杂交信号估计表达的芯片技术。
- **TPM**：按基因长度和测序深度标准化的表达量单位。
- **log2(TPM+1)**：压缩极端表达值并保留零值的常用变换。
- **Denominator（分母）**：计算比例时作为总数的病例数。
- **Imputation（插补）**：用统计方法填补缺失值；外部不可用分级没有被插补。
