# Main Table 4

This folder contains the manuscript-ready Agent benchmark table corresponding to Figure 4.

- `Table_4_Agent_Benchmark.xlsx`: formatted workbook for manuscript use.
- `Table_4_Primary_Agent_Benchmark.csv`: prespecified B2-versus-B4 endpoint.
- `Table_4_Ablation_Effects.csv`: four component ablations.
- `Table_4_Fault_Handling.csv`: eight frozen fault types.
- `source_data/`: locked numeric sources, terminology audit, provenance, and source gate.
- `TABLE_4_TITLE_AND_NOTES.md`: manuscript title and footnotes.
- `QA_REPORT.md`: final integrity and visual quality report.

Development and pilot outputs are excluded. The workbook uses only the complete formal run and the completed offline scoring audit.
