# Table 2 中文详细解读：TCGA-LIHC内部模型性能与正式配对比较

## 一句话结论

Table 2保存Figure 2所压缩的精确数字：M4在Harrell C、Uno C、12/36个月AUC和IBS的平均值上表现最好，但M4对临床模型M1的Harrell C和Uno C优势经Bonferroni校正后均不显著；M5则在Uno C上显著差于M1。

## 为什么要做这张表

图适合展示分布和趋势，但不适合让读者查找所有模型、所有时间点和完整置信区间。Table 2承担精确结果层，回答：

- 五个模型分别用了什么预测变量和算法。
- 25个外层折的平均性能和波动多大。
- 主要模型比较的差异、置信区间和校正P值是多少。
- 哪些结论只是描述性排名，哪些经过正式推断。

这张表还防止只挑选M4最有利的指标进行报告。

## 使用的数据

- TCGA-LIHC 363名患者、129例死亡。
- 5次重复×5个外层折，共25个外层测试折。
- 所有预处理和超参数选择在训练折内完成。
- 每个模型1,815条折外预测，总计9,075条。
- 正式模型比较使用363名患者的配对折外记录。

模型定义：

- M1 Clinical Cox PH：年龄、AJCC分期、肿瘤分级。
- M2 Gene elastic-net：15个锁定代谢基因。
- M3 Combined elastic-net：临床变量加15个基因。
- M4 Combined RSF：临床变量加15个基因的随机生存森林。
- M5 DeepSurv：临床变量加15个基因的神经Cox模型。

## 分析方法

### Section A：25个外层测试折的描述性汇总

每项指标报告25个外层折的均值和标准差。标准差描述不同折之间的波动，不是均值的标准误，也不是患者层面置信区间。

高值更好的指标包括Harrell C、Uno C和时间依赖AUC；低值更好的指标为IBS。

### Section B：正式患者层面配对Bootstrap

每次从363名患者中有放回抽样；同一抽样患者用于两个比较模型和全部5次重复。先在各重复内计算模型差，再平均5个重复，形成1,000个有效重抽样差异。95% CI使用百分位法。

在Harrell C和Uno C两个指标家族中，各有4个正式比较，因此P值分别使用Bonferroni校正。显著性判断必须基于校正P值，而不是原始P值。

## Section A如何阅读

### M1：临床参考

- Harrell C 0.597（SD 0.065）。
- Uno C 0.615（0.066）。
- 12、36、60个月AUC分别为0.637、0.644、0.641。
- IBS 0.196（0.012）。

M1代表仅使用常规临床变量的参考性能。其他模型的价值应与它比较，而不只与0.5随机线比较。

### M2：仅基因模型

- Harrell C 0.619。
- Uno C 0.601。
- 12、36、60个月AUC为0.650、0.650、0.619。
- IBS 0.192。

M2的Harrell C高于M1，但Uno C和60个月AUC没有同步改善，说明单一指标不能概括全部性能。

### M3：临床加基因线性模型

- Harrell C 0.623。
- Uno C 0.608。
- 12、36、60个月AUC为0.659、0.660、0.629。
- IBS 0.192。

联合线性模型在多项均值上略优于M2，但正式M3对M2比较并不显著。

### M4：临床加基因随机生存森林

- Harrell C 0.641（0.057）。
- Uno C 0.627（0.052）。
- 12、36、60个月AUC为0.676、0.670、0.639。
- IBS 0.184（0.015）。

M4的平均Harrell C、Uno C、12/36个月AUC和IBS为五个模型中最好，因此按预设选择规则保留为暂定主要候选模型。60个月AUC 0.639略低于M1的0.641，提醒读者“总体最好”并非每个单项都最好。

### M5：DeepSurv

- Harrell C 0.479。
- Uno C 0.486。
- 12、36、60个月AUC为0.474、0.452、0.489。
- IBS 0.209。

M5平均判别接近或低于随机，且标准差较大。它是探索性深度学习比较模型，结果说明复杂模型在363例数据上不一定更好。

## Section B如何阅读

### Harrell C比较

- M3对M1：+0.053，95% CI −0.013至+0.112，校正P=0.488。
- M4对M1：+0.078，95% CI +0.017至+0.138，原始P=0.024，校正P=0.096。
- M5对M1：−0.079，95% CI −0.143至−0.015，校正P=0.096。
- M3对M2：+0.001，95% CI −0.016至+0.018，校正P=1.000。

M4的区间不跨0，但校正P仍大于0.05。这不是矛盾，而是置信区间和P值对应的校正方式不同：表中CI为未做多重校正的百分位区间，而显著性使用校正P值。

### Uno C比较

- M3对M1：−0.006，校正P=1.000。
- M4对M1：+0.014，95% CI −0.041至+0.065，校正P=1.000。
- M5对M1：−0.130，95% CI −0.186至−0.074，校正P=0.008，显著更差。
- M3对M2：+0.007，校正P=1.000。

Uno C考虑删失权重后，M4对M1的差异明显小于Harrell C差异，进一步支持谨慎表述。

## 对整篇论文的意义

Table 2为候选模型选择提供完整证据：M4有最强的描述性总体表现，但未达到“统计学显著优于临床基线”的标准。它使论文可以合理选择M4作为后续候选，同时避免把选择结果夸大成确证性胜利。

这张表也记录M5的负面结果，说明研究没有因为深度模型表现差就将其隐藏。对高风险生物医学AI论文，透明呈现失败模型有助于降低选择性报告风险。

## 能说明什么、不能说明什么

可以说明：

- M4在多数平均内部性能指标中排名第一。
- M4对M1的平均Harrell C差异较大，但校正后不显著。
- M5在Uno C上显著差于M1。
- 复杂度增加并不保证性能提升。

不能说明：

- 不能写“M4全面或显著超过所有模型”。
- 不能把25个折当成25个独立临床队列。
- 不能把均值标准差当作患者层面95% CI。
- 不能从内部验证推断外部临床效用。
- 不能因为一个P值不显著就断言两个模型完全等效。

## 术语解释

- **Predictor（预测变量）**：输入模型的临床或基因特征。
- **Algorithm（算法）**：从输入计算风险或生存概率的规则和训练方法。
- **PH（Proportional Hazards，比例风险）**：Cox模型假设组间风险比随时间相对稳定。
- **Elastic-net Cox**：带L1和L2惩罚的Cox模型。
- **RSF**：随机生存森林，通过多棵生存树学习非线性关系。
- **Neural Cox model**：用神经网络替代线性风险函数的Cox型模型。
- **Mean（均值）**：25折指标的算术平均。
- **SD（标准差）**：25折指标的离散程度。
- **Discrimination（判别能力）**：模型把高风险患者排在低风险患者之前的能力。
- **Calibration（校准）**：预测概率与实际发生比例是否一致；本表主要报告判别和误差，不以C-index代表校准。
- **Raw P value（原始P值）**：尚未考虑多重比较的P值。
- **Adjusted P value（校正P值）**：考虑同时进行多个检验后的P值。
- **Multiplicity（多重性）**：同时检验多个假设导致偶然阳性概率增加的问题。
- **Percentile CI（百分位置信区间）**：取Bootstrap结果分布的2.5%和97.5%分位数。
- **Comparator（比较模型）**：用于与候选模型进行正式比较的参考方法。
- **Provisional primary candidate（暂定主要候选）**：按预设规则选出的下一阶段首选模型，但尚未被外部确证。
