# Main Table 2

This folder contains the manuscript-ready internal validation table for TCGA-LIHC.

- `Table_2_Internal_Model_Performance.xlsx`: formatted workbook for manuscript use.
- `Table_2_Internal_Model_Performance.csv`: model-performance section.
- `Table_2_Model_Comparisons.csv`: prespecified paired-comparison section.
- `source_data/`: locked numeric inputs, provenance, and source gate.
- `TABLE_2_TITLE_AND_NOTES.md`: manuscript title and footnotes.
- `QA_REPORT.md`: final integrity and visual quality report.

The canonical comparison source is `model_comparisons_v6.csv`. Earlier comparison files are intentionally excluded.
